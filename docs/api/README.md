# Postcodeloterij API Reference

This directory contains reference documentation for the Postcodeloterij public REST API endpoints used by this integration.

## Endpoints

| File | Endpoint | Description |
|------|----------|-------------|
| [winnings.md](winnings.md) | `POST /public/rest/drawresults/winnings/NPL/P_MT_P{YYYYMM}/` | Prize results for a given postcode and draw period |

## Base URL

```
https://www.postcodeloterij.nl
```

## Authentication

No authentication required. The API is publicly accessible.
